# Browser Iso World Skeleton

Каркас браузерной изометрической игры:

- процедурный мир;
- ресурсы;
- сбор;
- строительство;
- крафт;
- кастомизация персонажа;
- поддержка ПК и мобильных браузеров.

## Стек

- Phaser 3
- TypeScript
- Vite
- GitHub Pages
- GitHub Actions

## Локальный запуск

```bash
npm install
npm run dev
